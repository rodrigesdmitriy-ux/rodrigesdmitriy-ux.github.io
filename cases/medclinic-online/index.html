Онлайн-запись для сети клиник

Менеджеры сети клиник весь день сидели на телефоне. Я сделал онлайн-запись по реальному расписанию врачей и Telegram-бота для напоминаний. Нагрузка на менеджеров снизилась вдвое.

Клиент
Сеть медицинских клиник (по NDA)
Год
2021⁠–⁠2022
Роль
Team Lead / PM
Срок
4 месяца до запуска, затем поддержка
−50% нагрузка на менеджеров

Задача

70% рабочего времени менеджеры тратили на звонки: подтвердить, перенести, напомнить. Расписание врачей жило в Excel, пациент узнавал о свободном времени только по телефону. Заявки в нерабочие часы терялись.

Решение

Сделал на сайте запись по реальному расписанию врачей и услуг. Telegram-бот подтверждает запись, напоминает за сутки и переносит её в одно касание. Все заявки сходятся в CRM клиники, менеджер видит поток в одном окне.

  • Онлайн-запись на сайте по реальному расписанию
  • Telegram-бот: подтверждение, напоминание, перенос
  • Синхронизация с CRM клиники
  • Несколько филиалов и категорий услуг
  • Аналитика загрузки врачей в админке

Результаты

  • −50%Нагрузка на менеджеровзвонков стало вдвое меньше
  • 5 минОбработка заявкибыло 30⁠–⁠40 минут
  • 24/7Запись открытаночью и в выходные

Менеджеры освободили половину рабочего дня. Пациенты записываются ночью и в выходные.

Цифры в кейсах относятся к конкретным проектам.

Стек

  • PHP
  • 1С-Битрикс
  • MySQL
  • Telegram Bot API
  • REST API
  • Вебхуки
  • Linux
  • nginx

Технические детали

Бэкенд на PHP и 1С-Битрикс, REST API для бота, Telegram Bot API. Расписание в MySQL с индексами по филиалам, слот блокируется на время записи.
